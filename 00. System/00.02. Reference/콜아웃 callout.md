# 형식

```
> [!식별자] 변경할 제목
> > Here's a callout block. 
> > > It supports **Markdown**, [[Internal link|Wikilinks]], and [[Embed files|embeds]]! 
> > > > ![Engelbart.jpg]]
```

유형 식별자 바로 뒤에 더하기(+) 또는 빼기(-)를 추가하여 콜아웃을 접을 수 있게 만들 수 있습니다.
콜아웃을 여러 수준에 중첩할 수 있습니다.
